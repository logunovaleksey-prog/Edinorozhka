# Единорожка

Детская игра «Единорог в облаках». Шесть уровней придумала дочка:

1. Облачная тропинка — дойти до замка на большом облаке.
2. Найди алмаз — прыжки по облакам и радужная лестница.
3. Капельки на двоих — свинка, сосиска или котик, кто соберёт больше.
4. Котики-волшебники — серый и рыжий котики превращаются в разных зверей.
5. Подводное плавание — доплыть до большущего пузыря и лопнуть 10 пузырей пальцем.
6. Пузыри в небе — лопнуть 22 пузыря.

Играть лучше на телефоне, повернув его боком.
